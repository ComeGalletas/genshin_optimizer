# FILE-MAP

The directory index agents jump to instead of crawling the tree.

**Hand-maintained** — update it in the same commit that adds a top-level
source directory (or moves one). Each Purpose is the directory's own TSDoc
`@packageDocumentation` block, condensed to one sentence; the Source files
column counts `.ts`/`.tsx` files directly in that directory, tests included,
and is a rough orientation aid rather than a checked invariant.
