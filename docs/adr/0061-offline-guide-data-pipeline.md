# 0061. Offline scripts for the guide data

- Status: Accepted
- Date: 2026-10-07
- Amends: [0059](0059-several-builds-per-character.md),
  [0060](0060-genshin-gg-cross-check.md)

## Context

A review on 2026-10-07 mapped every data source the app uses:

- **Generated by scripts:** genshin-db's stats, texts and image names
  (`npm run build:data`), the genshin.gg cross-check, and the gcsim support
  table.
- **Transcribed by hand or by AI agents:** everything else. The 200 guide
  builds (ADR-0059) were read by four agents, and their raw data stayed in a
  session's temporary folder. So the app's builds couldn't be rebuilt or
  refreshed from the repo.

The owner asked for offline scripts that read the guide sites and feed the
app's data files: builds, default teams and character exceptions. SQLite
stays for account imports only.

The sources' rules allow it:

- KQM's, genshin-builds' and genshin.gg's robots.txt files allow crawlers;
  genshin-builds names AI agents explicitly.
- None of the three links terms of use that forbid it.
- Game8 stays out (ADR-0060).

## Decision

### Two steps, each by hand

1. **`npm run sources -- <source>`** (a server CLI, `packages/server/src/cli/sources.ts`)
   reads one site into its file in `data/sources/`:
   - `kqm`
   - `genshin-builds`
   - `genshin-gg`
2. **`npm run data:guides`** (`scripts/data-guides.ts`) merges those files
   into the app's data:
   - `meta/guideBuilds.ts`, by ADR-0059's rules;
   - `meta/genshinGg.generated.json`.

   `--check` fails when the data and the sources disagree. A test enforces
   the same thing.

The app never runs either step.

### Fetching politely

`packages/server/src/sources/fetch.ts`:

- reads each site's robots.txt and skips a disallowed path;
- names itself in its user agent;
- waits a second between requests to one site;
- uses plain page fetches only;
- keeps every page in `var/cache/sources/` (git-ignored), so reading again
  never refetches unless asked (`--refresh`).

### Reading: pure parsers in the engine

`packages/engine/src/sources/` turns a page into builds in dataset keys,
with no I/O, tested on made-up pages. No third-party HTML is kept in the
repo.

- **genshin-builds:** builds and teams come from the page's serialized
  component data (role, a "recommended" flag, ranked sets, main stats per
  slot, stat priority; team tiers and members). Nothing is read from prose.
- **genshin.gg:** its one template: role, ranked sets, main stats,
  substats.
- **KQM quick guides:** each build is a section holding "Artifact Stats"
  (a Sands / Goblet / Circlet table and a stat-priority line) and "Artifact
  Sets". The parser handles:
  - builds that share one section under sub-headings;
  - stat-priority variants ("EM Build", "CRIT Build");
  - sets tied in one cell, and 2+2 pairs;
  - Energy Recharge tables matched to builds by name, with weapon columns
    kept apart from team columns.

  KQM's misspellings and shorthand ("Emblem of Severe Fate", "TotM",
  "Husk") are read loosely and flagged.

### Nothing guessed

- Anything read loosely or not at all is flagged in the file. Every run
  writes a report to `var/reports/` saying what changed and what to check.
- When a fresh read misses something the previous read had (a role a page
  doesn't name, a main stat or substat line it couldn't read), the previous
  value stays, flagged.
- A page that can't be read at all keeps what the file had.
- `--llm` (KQM only) asks the configured language model (`config/llm.json`)
  to settle an unclear role or a missing substat line. Its answer is checked
  against the dataset's keys and flagged as the model's.
- The owner reviews the report and the diff before committing.

### The starting point

`data/sources/` was seeded from the 2026-10-07 agent pass (`readBy:
"agents"`) and the committed genshin.gg data. Merged, they reproduce the
app's data exactly. Applying a fresh read is a separate, reviewed change.

### Character exceptions

`npm run sources -- exceptions` scans genshin-db's kits for candidates
for `UNUSED_STATS`:

- a burst with no energy cost (Energy Recharge does nothing);
- a passive that takes away CRIT Rate.

It found exactly Mavuika, Skirk and Kokomi, the three entries set by hand.
New exceptions are still confirmed by the owner and added by hand.

### Teams: a test only

`npm run sources -- teams` compares genshin-builds' teams with the curated
team archetypes and only writes a report. Marked in the TODO as a test,
not development (owner, 2026-10-07). It's the starting point for 10.1's
"teams from the build sources".

## Consequences

- The guide data can be rebuilt and refreshed from the repo.
- A first fresh read (KQM: 113 of 120 pages read; genshin-builds: 120;
  genshin.gg: 118) differs from the agents' data for 94 characters. It
  changed no band on the owner's account; only Yaoyao's score moved, 26.2
  to 23.4. Most differences are build names, role labels and set lists:
  - the script reads roles from the sites' labels where the agents used
    judgment;
  - genshin-builds' Energy Recharge figures in its prose are no longer
    read.

  It waits for the owner's review in `var/reports/`.

- Six KQM pages have no build sections in the expected layout (Aloy,
  Mavuika, Mona, Tartaglia, Xinyan, Yanfei). They keep the agents' data
  until the reader learns their layout.
- The genshin.gg script is now `npm run sources -- genshin-gg`
  (`scripts/extract-genshin-gg.ts` is gone).
